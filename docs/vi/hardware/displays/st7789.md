# Connect an SPI color display to an S3 breadboard

This guide covers the separate-I2S wiring of `bread-compact-wifi-lcd`. It retains basic S3 audio pins and replaces the OLED with an SPI LCD. The camera build uses a different configuration.

<a name="scope"></a>

## 1. Identify the display {#scope}

Use an SPI module with a driver board that supports the required voltage. Check the controller, resolution, CS, reset, backlight, and pin count. The module's silkscreen matters more than its product title.

The default v2.6.0 build for this board is **ST7789 240×320**. Not every ST7789 display uses that size. A 240×240, 170×320, or seven-pin display without CS requires matching parameters or adaptation.

<a name="wiring"></a>

## 2. Connect by signal name {#wiring}

Disconnect power before wiring. Identify GPIOs by labels rather than counting pins from the left or right of a photo.

| Display signal | Board GPIO |
| --- | --- |
| SCL / SCK | GPIO21 |
| SDA / MOSI | GPIO47 |
| DC | GPIO40 |
| RES / RST | GPIO45 |
| CS | GPIO41 |
| BL / backlight control | GPIO42 |
| GND | Common GND |

Power input and backlight circuitry depend on the module. A `VCC` label does not establish 5V compatibility, and a backlight pin may not be directly drivable by a GPIO. Check power, enables, and load against the schematic.

Microphone WS/SCK/SD uses GPIO4/5/6; amplifier DIN/BCLK/LRC uses GPIO7/15/16. See the [basic build](../breadboard-esp32-s3.md). Remove the OLED's GPIO41/42 wiring before connecting this LCD.

## Full layouts for 44-pin and 42-pin boards {#wiring-diagrams}

Both diagrams use the LCD signals in the table above. Locate GPIOs on your board's layout. **The pictured display is 240×240, while the default build is 240×320; select matching display parameters. The diagrams power amplifier VIN from 3V3. If using the basic S3 USB 5V arrangement, follow that build's amplifier power and SD/GAIN settings.**

## 3. Build and test {#build}

Check the exact board and its options in the [online builder](../../firmware/online-builder.md). For other display parameters, use the [local build environment](../../development/build-firmware.md) and [versioned configuration](https://github.com/78/xiaozhi-esp32/blob/4de00aed740595a8713b01f8332b9b2cf30685bc/main/boards/bread-compact-wifi-lcd/config.h).

Use a [separate build identity](../../development/custom-board.md) for pin changes or new variants. Maintaining v2.0.2/v2.2.6 devices requires their corresponding source versions; they are not current builds.

### Verify the result

Check full-screen output, orientation, colors, and backlight control. Test prompt audio, the microphone, and a conversation. If only the backlight works, check SPI, reset, CS, and driver selection. For offsets or clipped images, check resolution, offsets, mirroring, and SPI mode rather than changing pins at random.
