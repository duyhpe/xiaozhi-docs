# v2.6.0 firmware downloads

**v2.6.0 is an official release.** This page is fixed to that version. See the [official v2.6.0 release](https://github.com/78/xiaozhi-esp32/releases/tag/v2.6.0) for complete release notes and assets.

<a name="online"></a>

## Prefer online installation {#online}

Most devices and breadboards can [build and flash in the XiaoZhi Console](https://xiaozhi.me/console/firmware-builder). Follow the [online guide](../online-builder.md) to choose board, language, and features. Use the packages below when you need offline files or the official release's default configuration.

Devices without an exposed USB download interface cannot connect through the browser alone. Check [flashing preparation](../flashing.md#prepare) against the board's interfaces first.

<a name="download"></a>

## Find firmware by board {#download}

Find your product and chip, then check display, network type, and hardware revision. Click the complete filename to download the ZIP directly. You can also use browser find (Ctrl+F / ⌘F) for a product name or model.

The tables contain **200 packages (199 regular packages and one Ethernet test build)**. `ESP32-P4 Rev1` and `Rev3 (P4X)` are listed separately and are not interchangeable. Manufacturer prefixes are part of the filename.

<a name="install"></a>

## Check the image type after extracting {#install}

1. Retain the ZIP filename and version, then inspect the extracted images and instructions.
2. Distinguish complete images, OTA application images, and multi-file output. Follow [Image types and write addresses](../flashing.md#image-types). Do not write an application image at `0x0` as if it were a complete image.
3. GitHub's automatically generated **Source code** archives contain source, not compiled device firmware.
4. For partition-layout changes, board changes, or downgrades, check update limits and prepare to reprovision. Do not assume every variant supports direct OTA.

<a name="version"></a>

## Versions and reproducibility {#version}

The online builder may show the same version number while using a different source commit or build options. Record version, commit, board variant, and download source when troubleshooting.

The firmware repository maintains full changes and build requirements. See [v2.6.0 source](https://github.com/78/xiaozhi-esp32/tree/v2.6.0) and [release notes](https://github.com/78/xiaozhi-esp32/releases/tag/v2.6.0). For code changes, continue with [Local builds](../../development/build-firmware.md).
