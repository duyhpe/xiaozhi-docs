# MCP và các công cụ mở rộng

Hãy bắt đầu với một công cụ tối giản, sau đó kết nối với các dịch vụ có sẵn hoặc tự viết ứng dụng của riêng bạn. Kiểm tra tách biệt ba giai đoạn: khả năng khám phá công cụ, lượt gọi hàm của mô hình và quá trình thực thi thực tế.

| [Kết nối các dịch vụ MCP có sẵn](./connect-existing-servers.md) | Phân biệt các giao thức stdio, SSE và Streamable HTTP khi kết nối dịch vụ vào trợ lý. |
